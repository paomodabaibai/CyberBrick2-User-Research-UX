**目标：** 第三根自动回中单轴摇杆控制巴掌连续旋转舵机：一侧持续正转，另一侧持续反转，松手回中停止；支持与现有行走同时运行。

### 配置基线

以下是首版候选，不是全都已实测；默认enabled=False完成PC测试后再随部署明确启用。

```python
ATTACK = dict(
    enabled=False, actuator='continuous',
    channel=2, center=1860, span=1800, direction=1,
    gpio=21, freq_hz=50,
    neutral_us=1500, delta_us=100,
    enter_deadband=0.15, exit_deadband=0.10,
    reverse_dwell_ms=150,
)
```

center按任务一实测替换。direction只在用户确认方向相反时改为-1。1500/±100对应候选1400/1500/1600µs，不扩大到500–2500µs。停止中位按实际不爬行校准。

### 接口与行为

```python
# attack_control.py
class AttackController:
    # update每拍返回目标脉宽；None表示禁用/失联/尚未回中，需要停止并释放。
    def __init__(self, cfg): ...
    def update(self, raw_frame, now_ms): ...

# drivers/palm_pwm.py
class PalmPwmDriver:
    def __init__(self, cfg): ...  # 不创建PWM
    def write_us(self, pulse_us): ...  # 首次需要时创建 GPIO21 的50Hz PWM
    def stop(self): ...  # 已创建才写neutral，不为了停止创建PWM
    def release(self): ...  # neutral -> duty(0) -> deinit；可重复调用
```

以上是接口约定，由执行者实现，不要将省略号当作成品上传。无需扩大UnifiedInput的所有调用点，直接复用input_adapter.valid_frame及原始frame[2]即可。

- [x] 先写行为测试，再实现纯逻辑控制器：
  - 使用 `axis=clamp((raw-center)/span*direction,-1,1)`；不是舵机角度。
  - 启动时未armed；首次有效帧且abs(axis)<=0.10后armed。启动杆偏着不转。
  - 停止时越过±0.15启动；运行时回到±0.10以内停止，形成滞回，避免中位抖动。
  - armed且中位时输出neutral；一侧输出neutral+delta、另一侧neutral-delta，与偏转幅度无关。
  - 直接跨向另一侧时先neutral至少150ms，再反向；用timeutil.diff_ms计时，不sleep阻塞主循环。过渡中松手取消反转。
  - 帧None/格式错误/禁用立即解除armed，输出None。失联恢复后，杆仍偏着也不自动再转，先回中。
  - 未变化的杆量是有效持续命令，不能凭值不变判失联。
- [x] 驱动只接受neutral±delta范围的脉宽，超出报错；不得创建S1–S4、GPIO20或改腿部PWM频率。
- [x] 只在目标变化时写脉宽即可，硬件PWM会持续输出。stop/release不使用长等待；正常中位保留neutral脉冲，退出或失联释放。

### 最小测试用例（必须明确断言）

使用10元素有效帧，ch2替换为测试值，其余轴为中位、按钮为1：

| 输入序列 | 预期 |
