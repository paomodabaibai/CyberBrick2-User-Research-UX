## 先确认遥控，不动作

```python
import second_punch_remote as p
p.monitor(15)
```

依次移动左行走杆、右行走杆、出拳杆、按 K4，记录十通道帧的变化与松杆中值。默认暂借第一台映射：左 ch3 / 1797，右 ch0 / 1959，攻击 ch2 / 1825，K4 ch9（按下 0、释放 1）。不能把默认值当第二台已验收映射。无帧时先检查配对，不运行动作。

按实测值建立配置，例如：

```python
mapping = dict(left=3, right=0, attack=2, stop=9,
               left_center=1797, right_center=1959, attack_center=1825)
```

## 依次短测

开始前所有杆回中、K4 松开；连续回中 0.5 秒后显示 ARMED。

```python
p.run(seconds=10, mode='attack', mapping=mapping)
p.run(seconds=10, mode='walk', mapping=mapping)
p.run(seconds=15, mode='both', mapping=mapping)
```

一次执行一条，观察结束后再进行下一条。attack 不创建腿 PWM；walk 不创建电机驱动；both 在同一循环并发。

行为：两行走杆同向推为前进，同向拉为倒退，单杆为弧线转向。第二台倒退/转向尚未实机验收，先托住观察。采用第二台已验证的髋 20°、踝 16°、偏置 4°、周期 1000ms；转向分幅 10°、直行配平 0，不复制第一台的更大振幅或配平值。

出拳杆任一方向过阈值均使用 M1 正向 1024（半速），不提供电机反转。松杆或回到中间过渡区域停机；连续运行最多 1.5 秒，必须完全回中才重新触发。这是连续曲柄机构的短时运行，不保证单次出拳或收拳归零：没有回零传感器。

K4 按下、无帧、坏帧：停电机并释放腿 PWM。恢复连接且所有杆回中 0.5 秒才能重新使能。Ctrl-C、时限到或异常同样停止电机并释放腿 PWM；释放 PWM 不切断电源，托住机器人避免失去支撑。

官方 API 没有包时间/序号；失联处理依赖 rc_slave_data 返回 None。第二台须实测关闭遥控器时是否停机，旧帧缓存不能靠本程序可靠辨别。首次并发测试只做短时观察，关注供电复位、卡滞和机构扫掠。
