# CyberBrick 2.0 · 可交互 H5

基于 [Figma 设计稿](https://www.figma.com/design/e3jDhP0HbtQao537wypZgz/2026-CyberBrick-2.0?node-id=201-626) 制作的手机端 App 概念演示。以 **375 × 812** 为移动端设计基准，支持手机与桌面响应式展示。

## 打开方式

双击 `index.html` 或 Windows 下的 `打开应用.cmd`，即可使用默认浏览器体验。**无需安装、无需启动服务、无外部运行依赖。**

也可将整个目录上传到静态网站托管服务，通过链接在手机上访问。请保持目录结构，并保留 `assets` 文件夹及全部 HTML、CSS、JavaScript 文件。

## 可以体验

- **首页**：浏览瀑布流、搜索作品、打开详情、点赞、收藏与关注创作者。
- **设计**：浏览与筛选模块商品、加入购物袋、调整数量、创建和查看模拟订单。
- **发布**：发布帖子、配件信息或模块分享，上传封面图片，保存和继续编辑草稿。
- **组装**：查看演示设备与组件、切换连接状态、预览动作并使用方向按钮操控动画。
- **我的**：查看创作、收藏和赞过的作品，编辑昵称与个人简介，管理草稿和订单。

## 数据与演示范围

点赞、收藏、关注、发布内容、草稿、个人资料及模拟订单使用浏览器 `localStorage` 保存在本地，不会上传。不同浏览器、设备或访问地址之间不会自动同步；清除浏览器数据或在设置中重置演示，会清除对应本地记录。浏览器禁止存储或空间不足时，应用仍可在当前会话使用，并提示保存限制。

设备连接、硬件状态、账号统计、商品参数和交易均为概念演示数据。此项目没有后端，不连接真实机器人；模拟下单不会扣款，也不会发货。
