# 双机2.0当前程序快照（2026-11-14）

蓝色巴掌2_D2与红色拳头2_M1是两个独立包，严禁混传。参数对应11月13日用户实测结果。本次在电脑组包，**没有重新上传到硬件**；蓝板原共享模块早于此快照（主要差别为可配置dance开关与启动提示），本包统一到已通过测试的当前源码，不宣称整包与板端每字节相同。

## 使用步骤
1. 安装requirements-serial.txt所列工具，识别接收板USB身份，备份板端文件及配对配置。
2. 保留官方固件、app/、bbl/、rc_config。包不含厂商驱动/固件，不能刷空板直接用；发射器沿用已配对发送程序，本次没有发射器固件包。
3. 包内commissioning_hold先上传，再上传本机各py文件（drivers目录按原结构），最后main.py、boot.py。SHA256.json是电脑核验清单，不必上传。
4. 重新启动，安装锁应阻止所有动作。核对接线、舵机90°装配、控制方向和站姿，做板端逐文件SHA256核对。
5. 人在场且机构就绪时，改名移走commissioning_hold后重启；遥控开机，全杆回中约1秒。完整入口会持续运行，不设测试倒计时。
6. 新红上慢下快、松杆停，K1按住跳；新蓝D2正反2100/900µs、松杆停，K1按住跳。先短试再持续观察。

不要上传整个控制框架根目录；其中main.py及旧待上传目录含历史方案。不要重复调用硬编码COM号的一次性脚本。若更新文件后仍运行旧代码，受控重启清理模块缓存。

## 范围
- 新红：左/右/攻击=ch2/ch5/ch3，K1=ch6，中位2002/1990/2115，慢1024快1800。
- 新蓝：相同通道但中位2069/1924/2132，D2=GPIO20，delta600。
- 四腿S1左髋/S2左踝/S3右髋/S4右踝。旧D1蓝机、旧单轴遥控器不能使用新配置。
- 突然卡住先物理断电，不把跳舞按钮当急停。不对连续舵机下发腿部90°归位。
