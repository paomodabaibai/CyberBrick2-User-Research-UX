# v06 双机接口修订：承重转盘与可操作的固定螺丝

2026-10-28。用户确认巴掌下垂主要发生在舵盘/连接块处，并指出拳头围挡遮住两个身体固定孔、后部存在多余孔耳。本轮在v05原高排布上改接口，不修改机器人程序。

入口：`双机接口v06_交互预览.html`；静态图在`预览`。这是结构审阅与试验模型，不是批量打印包。

## 巴掌：让支架承重，让舵盘传动

旧设计是小舵盘直接带着3mm厚横杆及75mm手掌，根部要同时承受驱动力和悬臂重量。用户观察到该处倾斜；本轮没有测量舵盘变形、内部齿隙或锁紧螺钉状态，因此不把某一种材料故障认定为唯一原因。

新设计的预期承力路径：

手掌 → 加强接杆与转盘 → 固定承重座/限位压环 → 四个安装点 → 舵机桥与内部支架。

原配舵盘保留原配中心锁紧螺钉，嵌入转盘底部槽口，通过两侧接触面带动转盘。槽底敞开，顶部留间隙，设计意图是不再依靠原舵盘承担手掌的竖向重量。实际是否完全卸载必须试装确认。

| 新零件 | 作用 |
|---|---|
| 11 新舵机桥 | 保留舵机位置，去掉旧头罩内柱结构 |
| 13 固定承重座 | 下方托住转盘，连接内部支架；外罩不作为主要承力件 |
| 14A、14B 两半限位压环 | 从两侧装入，限制转盘抬起和倾斜；每半两颗螺丝，无需把闭环硬套过接杆 |
| 15 转盘与加强接杆一体件 | 大直径根部承力，杆上两条肋加强；腕部旧接口保留 |
| 12 配套可拆罩 | 避开转盘及压环，保留拆装通路 |

身体39mm、手掌75mm、杆距51mm、接杆底面Z=39.97mm均不变。并没有通过抬高巴掌绕开问题。外罩远端角部限制在距转轴49mm以内，手掌网格最小半径约51mm，避免连续旋转时手腕扫到外罩角部。

### 试验性质与装配顺序

本版使用**打印滑动副**，不是已经验证的滚珠轴承方案。名义径向间隙0.3mm、轴向活动量0.4mm，舵盘槽侧隙0.3mm、上方间隙0.4mm。这些是试配起点，不是保证所有打印机都合适的尺寸。

1. 先安装原配舵盘与其中心螺钉；不将打印件直接压在花键上。
2. 固定承重座与舵机桥；四颗连接螺钉头要沉入座内，不能高出承托面。
3. 放入转盘，使底部槽口套住原配舵盘。不得靠拧螺钉强行压入不合尺寸的槽。
4. 两片压环从两侧合拢，拧紧到固定座，不夹紧转动件。
5. 先不装手掌检查整圈手动转动，再装手掌检查下垂；最后才通电低速正反转，检查起转、温升和电流。
6. 若出现摩擦过大、偏心卡滞或磨损，改滑动间隙/耐磨件，必要时再换真实轴承；不能只把PWM加大强行带动。

摩擦、耐磨、冲击强度、打印纹路、变形、回差和额外重量都没有实测。官方半臂舵盘CAD是槽口参考，实际360°舵机原配舵盘仍须核对。M3及原配螺钉长度、头型与工具空间需要在制造版逐项完成。

## 拳头：四个身体固定点都能从上方操作

- 保留身体原有四个固定轴位 `(±30, ±30)`。
- 后侧两个孔位 `(-30, ±30)` 的围挡改成敞开的U形工具通道。
- 护罩新增低位安装脚，与身体共用这两颗螺丝；装配顺序为护罩 → 模块底板 → 身体螺母座。
- 取消护罩原来位于 `(-46, ±28.5)` 的独立底部孔耳及其孔。
- 填平旧传感器预留孔 `(-24,-29)`、`(-8,-29)`；当前没有安装该传感器支架。
- 保留导杆固定孔、滑动连接、原电机托槽和扎带槽，不把有定位作用的孔一起删除。

新的共用夹紧叠层比旧版不同，**不能直接沿用未经核对的长螺钉**。v05后部有开关接插件，螺钉尖端与接插件的距离尚未在本轮模拟。正式试装前应核定螺母座高度与螺钉长度，并补完整个螺钉实体检查。

## 已验证与未验证

- 8个本轮新增/修改结构件均为单连通、闭合正体积网格，见`网格独立核验.json`。
- 22项列出的实体检查通过0.001mm³数值容差；其中承重座与舵机有约0.000016mm³数值残差，未把它隐藏成严格数学零。
- 转盘按每10°采样一周，与承重座、压环、外罩、舵机桥未发现体积重叠。不是实物旋转验证，也没有覆盖所有真实螺钉头和线束。
- 拳头四处固定点均按直径6mm的竖直工具柱检查，与修改后的底板/围挡无重叠；不等于所有尺寸的螺丝刀手柄都能伸入。
- v05原高排布的未完成事项继续有效：开关固定、充电维护面板、束带、全部实际插头、完整装配工具空间、强度和步态仍需完善。
