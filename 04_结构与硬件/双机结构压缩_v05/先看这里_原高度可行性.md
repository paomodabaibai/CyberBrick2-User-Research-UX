# v05 原高度排布可行性研究

日期：2026-10-28。用户要求尽量恢复旧高度，前提是结构可行。

## 当前结论

**26mm增高不是必需条件。按当前官方PC003电池、接收板组合与XA007开关模型，可以摆出身体39mm、攻击模块回到原高度的候选排布。** 这是名义几何与占位检查，不是已经完成制造设计或实物验证。

交互入口：`原高度结构v05_交互预览.html`。图片：`预览/v04与v05_同尺度高度对照.png`、`预览/原高内部布局.png`。

本目录不提供打印包。`装配网格`仅供预览与核验，不应直接发给组员打印。v04保留供对比，不修改既有机器人或固件。

## 如何省下26mm

| 项目 | v04增高版 | v05候选 |
|---|---|---|
| 身体高度 | 65mm | 39mm，顶部Z=0，底部Z=-39 |
| 攻击机构高度 | 整体增加26mm | 整体减回26mm；攻击件自身比例不缩放 |
| 主板 | 水平，针排朝上 | 后半部竖置，针排朝侧面，USB仍朝后 |
| 电池 | 平放底部 | 前侧立放，长51.2沿左右、厚16.3沿前后、高28.4 |
| 开关 | 侧后方 | 后背与USB分开；拨杆朝后外侧 |
| 身体主壳宽度 | 75mm | 仍75mm，非恢复旧69mm外轮廓 |
| 局部外形 | 前版扩宽 | 前电池仓让位，后背开关有4mm基座凸台，加2.4mm面板 |

电池本体边界X=18.2..34.5、Y=±25.6、Z=-35.5..-7.1；主板参考中心=(-17,5,-18)。电池不是裸电芯，不拆电池包装。实际电池若不是PC003，结论需重算。

插头仍按10mm加8mm弯线的18mm侧向占位预留，没有靠缩短这项假设压高度。但这只是四路针排附近的占位，**不是所有插头和电线已建模**。开关电池线、攻击线、线束交叉、弯曲半径需进一步核对。

## 已检查什么

`原高布局核验.json`记录74组实体/占位重叠检查，当前均为0：主板、电池、托架、开关闭合部件与身体、髋舵机占位、两型固定底座，以及针排侧向占位等列出的组合。

两侧髋占位与身体的交叠和旧模型基准一致（每侧约66.32mm³），没有新增交叠。该占位是保守盒体，不是最终供货SG90实物，不能据此宣称舵机装配或全运动范围通过。

接收组合13个实体中，两个接插件的三角网格不闭合，在网格碰撞检查时以各自外包盒保守替代；CAD实体之间的主板/托架检查另用实体求交。开关仅取可封闭且有效的PCB、主体与两个XH座检查，不把开放曲面的零体积当作无干涉。

## 为压缩而做的局部结构变化

- 前侧电池仓开凹腔，避开髋轴位；原身体需重打，不能将新电池布局强塞入旧壳。
- 前侧顶部螺母柱缩短至6mm，以避开电池上端；需要重新核定螺钉长度、螺母装入与强度。
- 竖向C形托架避开USB和核心板，底脚局部让开板端引脚；薄处、加筋和工具空间尚需制造细化。
- 后背开关凹腔会修整旧后部局部筋，新增凸台承接面板。需要补全开关耳固定柱、壳体螺母座及工具可达性后才能试打。
- 后面板上方为拳头隐藏过线槽让位。两型共用时，巴掌版该区域可用封片，尚未制作。

## 下一步：保证可装配，而非只看零件不重叠

1. 以本排布继续细化，保留原身体39mm及原攻击高度目标；不整体缩放模型。
2. 核对实际电池、舵机、针排母头、USB线头、开关与两端线头。重新检查电池线出线端及弯曲路线。
3. 完成开关固定、可拆主板托架的工具空间、前电池束带与取出路线；补回正面辨识装饰。
4. 设计独立可换充电维护面板。当前原高草案尚未布置该面板，更未实现Type-C充电；这一需求未取消。
5. 复核所有紧固件、前柱短螺母座、后腔加筋、后面板让线缺口、四关节运动范围；按实际切片检查壁厚、支撑和方向。
6. 先打单台身体/托架/接口试装，检查能合盖、插拔USB、拨开关、不夹线、能换电池，再通电验证重心、步态和攻击。

若真实线头装不下，优先调整局部槽和后背凸台；确实无法排布时才增加有依据的小幅高度，不默认回到+26mm。
