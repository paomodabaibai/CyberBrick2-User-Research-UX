# 对中工具使用说明（center_joint.py / bench_v02.joint）

配套：《四关节中位安装图_v01.svg》《逐关节安装记录表.md》。
本目录三份文件为**纯资料/代码件（阶段一交付）**，不代表机械校准已完成。

## 安装前提（阶段二现场，逐关节）

1. 托住机器人使脚悬空，物理断电开关在手边。
2. **松开/拆下该路可能受力的舵盘与腿脚连接**——首次中位命令可能让舵机突然转动
   （软件不知道断电前输出轴的位置），机械顶住时严禁强制回中。
3. 顺序建议：左髋 → 右髋 → 左踝 → 右踝。一次只做一路。

## 板上 REPL 操作

```python
import center_joint
center_joint.list()                                   # 只读：四关节 端口/GPIO/类型 + 行走就绪状态
center_joint.send('left_hip', confirmed=True)         # 90°中位并持续保持
center_joint.send('right_hip', confirmed=True, seconds=5)   # 保持5秒后自动关输出
center_joint.off()                                    # 立即关闭输出（PWM off）
```

要点：

- **一次只驱动一路（代码强制）**：`write_one` 单通道写；且 `send()` 切换到不同关节时会**先自动释放上一路的 PWM**——忘记调 `off()` 也不可能同时驱动两路（有桩 machine 测试锁定）。
- **定时关闭保证执行**：`send(..., seconds=N)` 的等待即使被 Ctrl-C 或异常打断，`off()` 也一定执行（try/finally，有测试锁定）。
- 通道按关节名 → `config.JOINTS` 的 port/gpio 查找，不按数组索引猜。
- **S2 拒发**：`left_ankle` 现为 360° 连续舵机（PG002）且 disabled，任何
  "90°定位"请求都会被拒绝；换装 180° PG001 并修改 config（enabled=True,
  actuator='position'）后自动放行——不改驱动源码。
- **90° = 电气中位**（500µs/2500µs 的线性中点 1500µs），故意不套 center/trim；
  trim 是装好舵盘之后的微调手段，不用大 trim 迁就错齿。
- 关 PWM ≠ 切断舵机电源；离场或急停请用物理断电开关。
- PC 彩排：`send(..., allow_sim=True)` 走 SimDriver，不发真实脉冲；默认在
  DRIVER='sim' 时拒绝执行，防止"软件跑了但舵机没动"的误判。

## 中位装好舵盘之后

小幅双向验证（托住状态）：

```python
import bench_v02
bench_v02.joint('left_hip', 5, confirmed=True)    # +5°，1.6s 后自动回中位并关输出
bench_v02.joint('left_hip', -5, confirmed=True)   # -5°
```

记录实际动作方向与不顶壳的安全范围 → 填《逐关节安装记录表》→ 用户确认 →
才改 `config.py`（center/trim/direction/min/max，最后 calibrated=True）。

## 导入安全承诺（有测试锁定）

`import center_joint` / `import bench_v02` 不创建 PWM、不连遥控、不动任何关节；
全部动作在显式函数内且需要 `confirmed=True`。tests/test_center.py、
tests/test_bench.py、tests/test_capabilities.py::TestWalkReadyMarkerHonesty 覆盖。
