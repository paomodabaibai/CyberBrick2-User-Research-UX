# 现场顺序卡｜阶段C 四关节机械对中与站姿（一页）

打印随身。安全红线：**全程托住机器人，物理断电开关在手边；一次只做一路；异常/卡住/异响立即断电。**
配套：《逐关节安装记录表》（逐格填写，填完一路才做下一路）；对中命令 `center_joint.py`（上传接收板后用）。
证据等级每行标注：②板端命令成功 ③观察者确认动作。

## 0. 开工前（5 分钟）

1. ☐ 串口重识别（按 USB 序列 58:E6:C5:A8:1B:0C 认接收板，勿假定 COM 号）
2. ☐ 板载文件哈希/清单核对；`bench_v02.diag()` 输出与记录一致
3. ☐ 确认四只舵机均为 180° 位置型（含左踝新 PG001）；S2 若仍 360° → **跳过左踝，走三路降级线**
4. ☐ 托住机器人使脚悬空；确认断电开关可及
5. ☐ 遥控器开机备用（K4 急停在后续流程验证，单关节对中靠断电开关兜底）

## 1. 逐关节循环（顺序：左髋 → 右髋 → 左踝 → 右踝）

每一路严格按此序，完成一步勾一步（记录表对应行同步填）：

```
① 拆开该路受力连接（舵盘螺钉/腿脚卡扣）                    ☐
② import center_joint; center_joint.list()   ← 只读核对端口   ☐
③ center_joint.send('<关节名>', confirmed=True)              ☐  ②
   ↳ 观察：舵机确实转到中位（会突然转动，勿扶在转范围内）      ☐  ③
④ 保持中位，装舵盘：最近齿位；明显偏斜→拆下重装，不用大trim   ☐  ③
⑤ 按安装图接回腿/脚（髋=站立方向；踝=脚底能平放）            ☐  ③
⑥ off() 关输出；装好后再小幅验证（托住）：
     import bench_v02
     bench_v02.joint('<关节名>', 3,  confirmed=True)   # +3°  ☐  ②③
     bench_v02.joint('<关节名>', -3, confirmed=True)   # -3°  ☐  ②③
   ↳ 观察：方向、平滑、无异响；逐步探不顶壳的范围              ☐  ③
⑦ 填记录表：型号/舵盘姿态/正方向实际动作/安全范围/trim       ☐
⑧ 用户确认 → 才改 config.py（center/trim/direction/min/max，最后 calibrated=True）  ☐
```

注意：`center_joint.send` 切换关节会自动关上一路（代码保证）；`seconds=N` 即使被 Ctrl-C 打断也会关输出。

## 2. 站姿验收（四路全部 calibrated=True 后）

```
① 托住发站姿：import main_v02; s=main_v02.start(link=main_v02.RcLink())
   s.enable()   ← 严格使能：四关节未全标定会拒绝（这是门禁不是bug）
② 观察后轻放桌面（短时）：
   ☐ 双脚底同时接触桌面        ☐ 机身无明显前后/左右倾斜
   ☐ 无持续顶死/抖动           ☐ 左右腿无挤压/内八外八
③ 正面+侧面照片 → 存《逐关节安装记录表》附件；照片注明"观察者确认"
```

**不满足 → 回机械安装/舵盘齿位，其次 center/trim/direction；不运行完整步态。**
