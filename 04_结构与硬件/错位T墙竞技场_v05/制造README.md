# 错位 T 墙竞技场 v05 · 制造说明

单位均为 **mm**。本包是可切片、可改尺寸的制造候选版，已完成数字几何检查；机器人高度、攻击扫掠、击打高度、目标配重、实际桌面尺寸、打印公差尚未完成实测。名义场地 **1260 × 1260**，单层平地，地板厚 **6**；所有墙、护沿和目标直接放在地板上。

## 文件用途

| 文件/目录 | 用法 |
|---|---|
| `stl/` | 每种零件一个 STL；**按 BOM 数量复制打印**，导入单位选 mm、比例 100% |
| `step/` | 单件可直接编辑的 BREP 实体；保留设计坐标，**不是打印摆放方向** |
| `assembly/arena_A_reference_only.step` | A 完整墙版装配参照，173 个独立零件，**不可整场打印** |
| `assembly/arena_B_reference_only.step` | B 低转向版装配参照，167 个在用零件；6 件横墙取下保留 |
| `BOM.csv` | 零件规格、A/B 数量、首印样片数量和文件索引 |
| `scene.json` | 地板编号、实例坐标、角度、颜色、分区及 A/B 启用清单 |
| `parameters.json` | 可复用参数输入，允许调整目标直径/高度/壁厚/底厚、目标位置和墙高等 |
| `build_arena.py` | CadQuery 建模、STL/STEP 导出、BOM/场景导出和数字校验脚本 |
| `geometry_report.json` | 本次导出后的检查结果；不是实物验证报告 |

STEP 是可编辑实体，不包含完整参数历史；参数由 JSON 与 Python 建模源提供。改动场地大小、模块节距、墙平面坐标时，还须修改脚本中的布局定义并重绘图纸。脚本目前主动校验 7 × 7、180 节距、6 厚、1260 场地等本版固定条件，防止仅改某个值后产生错配。重新运行会覆盖 BOM、场景、报告和同名模型，建议在复制版本中修改。

A 全套 **173 件**。B 使用同套零件，只取下 LH1、LH2、LH3、RH1、RH2、RH3，不需追加零件。主墙竖向外棱为 **R2**，包络尺寸保持不变。护沿拼成完整方框，角部无实体重叠。

首印另提供 C01/C02 接缝样片各 1 件（每片 39.8 × 40 × 6）与 T02 半高筒靶 1 件（外径 90、高 80）。从 J01 先打印 1 件用于接缝测试；正式装配仍需 84 件完好的桥片。T02 只检验壁厚成形和材料表现，不能替代 T01 的实际击倒测试。

最长单件 180；每侧预留 8 宽 brim 后占 196，名义 200 × 200 打印床还有每侧 2 余量。F01 含 brim 占 195.6 × 195.6。最高单件 160。应在自己的切片器中核对可用打印区、夹具避让与裙边设置；标称 200 并不等于所有机型都能使用完整边缘。

## 必须保持的打印方向

- **F01、C01、C02：平整行走面贴打印床，底面连接槽朝上。** STL 已旋转到这个方向，Z 最低为 0；不要为了看到平面而再翻转。打印后将零件翻面组装。这样底槽不需要支撑，行走面不会出现槽口。
- J01：大平面贴床。
- W01–W04、E01–E02：墙底/护沿底贴床，竖直打印。
- T01/T02：封闭底面贴床、筒口朝上；模型本身已带底，不能使用删除底部的设置。
- STEP 单件底面统一为设计 Z=0；F01 和样片 STEP 与 STL 的方向不同。按 STEP 自行切片时须重复上述翻转。

所有 STL 均已预摆方向，但本包**没有完成特定打印机的切片验证，也没有生成通用 G-code**。0.8 壁厚需要在切片预览中确认形成连续壁线，不能仅按喷嘴直径推断是否可打。建议先用 0.20 层高作为测试起点，实际线宽、材料、流量和桥片间隙以机器校准为准。墙体和地板的实体 CAD 不意味着必须 100% 填充；壳厚与填充密度须通过机器人载荷和碰撞试样决定。报告中的实心质量是体积乘假设密度 1.24 g/cm³，**不是预计耗材重量**。

## 底面接口与平整拼接

地板节距 180、实体边长 179.6，相邻地板名义净缝 **0.4**。四边各有一个底面半槽；两片靠拢后形成一组完整桥片槽。J01 外包络 44 × 18 × 2，中颈长 12、宽 8；槽侧余量 0.3、槽深 2.4。桥片厚 2，所以完全落槽后底面不凸出；槽上仍有 **3.6** 厚连续地板。数字检查中桥片与两片地板的体积交叠均为 0。

这是一组间隙配合定位片，**没有倒扣卡扣**，不应当成能独立托举整场的承重锁。桌面承担重量。若桥片容易从底槽脱出，可在底槽内部用薄可移胶点固定桥片；不得在地板底面叠出凸包。地板上表面、接缝和脚步经过的位置都不加突起连接件。

先打印 C01 + C02 + J01，在平板上组合：样片之间留 0.4 缝，底面无摇晃、顶面无可感台阶，桥片能够装入且不把样片撑开。清理毛边和首层象脚后再判断公差；尺寸不合时调整参数并重打样片，不要用强压装配替代匹配。随后至少打印两片 F01，用实际机器人进行跨缝、转身、负载和表面摩擦试验，再批量生产剩余板。

## 组装与编号

坐标原点为名义场地左下角桌面，X 向右、Y 向上、Z 向上。地板下表面 Z=0、行走面 Z=6。墙、护沿、目标的名义底面均 Z=6；模型没有把双面胶厚度计入尺寸。实体地板的最外边是 0.2…1259.8；外围护沿占名义边界 0…1260，外侧有 0.2 的名义悬边，不构成高架结构。

1. 在同一平整支撑面拼 7 × 7 地板。行从下到上 A–G，列从左到右 1–7，编号为 F-A1…F-G7。把编号写在板底；模型没有在行走面刻凸字。
2. 行内 6 个接口 × 7 行 = 42 片桥片；行间 6 条接口 × 7 列 = 42 片，总计 84。外边的剩余半槽不用填。
3. 南北护沿各用 7 段 E01。东西护沿各先沿 y20…1100 用 6 段 E01，再沿 y1100…1240 用 1 段 E02。四角由南北护沿占据，侧沿不再重复覆盖。
4. 按 `scene.json` 或附图放墙，使用薄可移胶固定。每组 4 段横墙的高度依次 60 / 80 / 100 / 80；两组绕场地中心相差 180°。支墙高 80。胶粘保持力须在机器人撞击试验后判断。
5. 红靶中心 (260,650)，蓝靶中心 (1000,610)。两枚靶均自由直立，**不粘地板、不加支架**，便于被击倒后复位。筒颜色表示攻击者：红方击倒红靶，蓝方击倒蓝靶。

护沿高 35、厚 20，用来定义活动边界；其抗推力、粘接力和对重型机器人的阻挡效果尚未验证，不能把它当作可靠防坠结构。使用的桌面应完整支承场地并留足实际机器人活动与倒伏余量。

## 首印后要记录的实测结果

| 对象 | 必须记录 | 用于决定 |
|---|---|---|
| 接口样片、两片地板 | 实际缝宽、台阶、翘曲、桥片松紧、表面摩擦 | 是否批量打印 49 片地板 |
| 两台机器人 | 含攻击机构的总外包络、转弯包络、有效击打高度与方向 | 墙高、通道、目标高度是否适配 |
| 旋转巴掌 / 往复拳 | 静止与攻击时扫掠、可从前/侧面击中区域 | 是否出现某一种攻击机构受墙遮挡 |
| 两个 T01 正式目标 | 质量、自然倒伏、被两种机构击倒难度、倒下后的范围 | 壁厚、底厚、目标位置与双方公平性 |
| 护沿与墙体 | 撞击位移、胶固定强度、拆装损耗 | 固定工艺与可复玩布置 |

135 的击打高度仅是模型参考。目标周边预留半径 230 的保守无墙区域，数字布局最小到固定障碍包络距离为 240；这个预留圈不是对实物运动的保证。两条支墙末端的包络角点 (540,500) 与 (720,760) 相距约 316.23，这是静态斜向净距，尚未证实机器人容易转弯或能顺畅通过。设计目标是先打印小样，把不确定尺寸留在可替换的目标和墙体上。

## 复现本包

```powershell
& 'D:/python/python.exe' '04_结构与硬件/错位T墙竞技场_v05/build_arena.py'
```

脚本在工作区内读取 `04_结构与硬件/cad_runtime/Lib/site-packages` 中的 CadQuery 与 trimesh。报告包括每个零件的有效实体、水密性、单连通、正体积、打印床包络；接口相交体积；固定障碍互不交叠；目标保留圈；A/B STEP 回读实体数。通过这些检查说明数字文件几何一致，**不等于已切片、已打印或已通过实体机器人对战**。
