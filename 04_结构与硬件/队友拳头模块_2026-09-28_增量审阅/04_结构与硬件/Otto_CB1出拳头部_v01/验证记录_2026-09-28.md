# 数字验证记录

日期：2026-09-28。未连接CB1、未上传程序、未驱动电机；不涉及原行走框架改动。

## 最终默认版本

实际运行：`python build_punch_head.py --sweep-step 10`。

- 运行环境：Windows / Python 3.11.5 / CadQuery 2.8.0，使用项目既存CAD包。
- 进程退出码0，状态 `DIGITAL_CHECKS_PASS_PHYSICAL_UNVERIFIED`。
- 9个自建打印件：各为1个有效BRep实体，STL网格闭合、正体积、1个连通体。
- 默认半径10mm，连杆孔距34mm，滑架铰点X=30..50mm，行程20mm。
- 0–360°每10°采样，共37个角度；所检查运动件对固定件、运动件之间的体积干涉均未检出。
- 新固定件对厂家壳体和马达包络的静态检查未检出体积干涉。
- 两个极限位置总装已导出STEP及GLB，预览PNG及运动GIF已生成。
- 最终预览又单独重绘以增强光照和观察角度，不改几何；可选传感器支架在预览中隐藏以显示传动，仍保留在总装模型。

详细检查范围及实体体积见 `output/validation.json`。每个打印件实际包络以该报告为准，不把体积当成切片耗材重量。

## 参数变体

将 `crank_radius_mm` 改为12，其余默认，得到24mm行程。在0/90/180/270/360°共5个关键角度复核，未检出所检查零件干涉，静态检查通过；并非对24mm变体做了相同密度的整圈采样。

记录保存在 `parameter_check_24mm/validation_24mm.json`。半径8mm、连杆4mm、身体宽90mm等不适配本布局的参数均被守卫拒绝。半径小于10mm需要重新设计曲柄轴套与转轴螺钉的避让，不能简单缩短曲柄。

## 修正过的问题

- 拳套复合圆角导出网格出现非闭合边，改用沿X方向的圆角结构，最终STL检查通过。
- 电机后部线材CAD与托盘后壁曾有约0.145mm³重叠，扩大走线口后复查通过。
- 平台与安装圈拆成两件，消除大跨度底部空腔顶板的打印问题。
- 扎带改为穿过平台的通槽，明确可装配的环绕路径；前部支撑梁落到平台Z=0，减少底部悬空。
