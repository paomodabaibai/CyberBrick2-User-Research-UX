# Otto / CB1 出拳头部 v01

组内同步请先阅读：[`出拳机器人头部_建模详细说明_团队同步版.md`](出拳机器人头部_建模详细说明_团队同步版.md)。

2026-09-28。交付内容是可运行的 CadQuery 参数化建模脚本、零件 STEP/STL、总装 STEP/GLB、往复运动动画和数字几何检查。此版为机构试装原型，未上机、未测试负载；不是已经验证能对战的成品。

用户最新确认：一台机器人顶部旋转巴掌已实现；另一台制作电机驱动出拳头部。手头电机是否带齿轮箱暂不确定，用户选择先按官方资料制作参数化版本。

## 1. 用哪个电机、怎样出拳

以官方 CB1 套件的 **LA024 030 有刷直流马达 + LA016 1:48 单轴减速齿轮组**为设计基准。LA016 是齿轮包，壳体为打印件；不能把裸马达轴直接接本版曲柄。

传动顺序：LA024 → LA016 减速器 → 双扁孔曲柄 → 连杆 → 双导杆滑架 → 可拆空心拳套。

- 减速器输出轴竖直，曲柄在水平面转动；拳头沿机器人前方直线移动。
- **一圈 = 完整打出 + 收回，不需要电机正反转切换。** 默认曲柄半径 10 mm，行程 20 mm。
- 连杆两孔中心距 34 mm；两根 Ø3×64 mm 金属导杆限制侧向移动，拳头不能只靠电机轴悬挂。
- 顶部沿用项目现有 Otto 身体外包络 69×69 mm，安装圈净开口 69.8×69.8 mm。
- 安装圈与平台分开打印，用四个外耳连接，避免在 69.8 mm 空腔上方打印整片悬空顶板。
- 当前是单拳头往复机构。参考 Punchy 的电机带动连杆思路，但没有照搬其轮式底盘、双拳联动或整套齿轮传动。

本版额外需要金属导杆、螺钉、间隔垫和扎带，**并非只用原套件就能装完**。详见 BOM.csv。

## 2. 文件怎么用

| 文件 | 用途 |
|---|---|
| `build_punch_head.py` | 完整参数化源文件，不连接硬件 |
| `parameters.json` | 可修改参数，尺寸单位 mm |
| `output/STL_打印件/` | 独立零件，已平移至打印平台 Z=0；需自行切片检查 |
| `output/STEP_可编辑实体/` | 各零件实体，保留设计/装配参考坐标 |
| `output/assembly_180deg.step / .glb` | 收回位置总装 |
| `output/assembly_000deg.step / .glb` | 打出位置总装 |
| `output/assembly_preview.png` | 两个极限位置预览 |
| `output/mechanism_motion.gif` | 俯视运动原理动画（示意层叠，不是动力学仿真） |
| `output/motion.csv` | 曲柄角度、连杆角度和滑架位移 |
| `output/validation.json` | 零件有效性、网格闭合与离散运动干涉检查 |
| `output/官方壳体_如已有则不重复打印/` | 从厂家 CAD 提取的两片减速箱壳体；不是本项目原创 |
| `参考资料/` | 原官方马达/减速器 CAD、规格 PDF 及核对图 |

所有 STEP/GLB 总装文件含多个独立零件，不可直接当作一体打印模型。供电板、电池、Otto 身体内部元件和传感器实体没有纳入总装。

## 3. 运行方法

在本项目已验证的方式：系统 Python 3.11.5 加项目已有 `cad_runtime/Lib/site-packages` 中的 CadQuery 2.8.0。原 cad_runtime 虚拟环境指向旧电脑路径，脚本自动复用它的包，不修改旧环境。

在本文件所在文件夹执行：

```powershell
python .\build_punch_head.py
```

或者从任意目录传入脚本完整路径。脚本以自身位置定位参数和参考 CAD，默认输出到自身目录下的 output。整圈检查需要数分钟。

```powershell
python .\build_punch_head.py --config .\parameters.json --out .\output --angle 180 --sweep-step 5
```

`--skip-render` 只跳过图片/GIF生成，不跳过几何检查。`--sweep-step` 为离散采样步长，范围大于 0 且不超过 15°；步长越小检查越慢。发生实体或网格错误会终止；发现碰撞则写出报告并以非零状态退出。

换电脑时可在独立 Python 环境安装 `requirements.txt`，并保留本文件夹的 `参考资料`。不需要 Blender、Fusion 或联网才能重新生成。输出会覆盖所选 output 目录下的同名生成文件，参数文件不会被覆盖。

## 4. 参数与可调整范围

| 参数 | 默认 | 作用 |
|---|---:|---|
| `crank_radius_mm` | 10 | 半行程；本布局允许 10–12，即总行程 20–24；更小半径需重做轴套与螺钉避让 |
| `rod_centres_mm` | 34 | 连杆两孔距；本布局允许 32–36，仍须通过行程边界检查 |
| `body_outer_mm` | 69 | 现有身体外宽 |
| `body_fit_per_side_mm` | 0.4 | 身体安装圈单边配合间隙 |
| `shaft_socket_radial_clearance_mm` | 0.15 | 从官方输出轴截面外扩的曲柄孔间隙 |
| `guide_rod_diameter_mm` | 3 | 金属导杆直径 |
| `guide_running_diametral_clearance_mm` | 0.45 | 滑架孔比杆直径大多少；默认滑孔 Ø3.45 |
| `guide_fixed_diametral_clearance_mm` | 0.15 | 固定支座孔间隙；默认 Ø3.15 |
| `guide_y_mm` | 20 | 两导杆距中心线距离，即中心距 40 |
| `pivot_hole_diameter_mm` | 3.2 | 两处 M3 转动连接通孔 |
| `fist_socket_per_side_mm` | 0.25 | 拳套对滑架舌头的单边间隙 |

参数化不等于任意值都有效。导杆支座位置、输出壳体以及部分紧固结构是本版固定布局；脚本会拒绝使滑架撞支座的参数。改变未实测间隙后应重新打印量规或单件试装。`gearbox_z_offset_mm` 只调整厂家组件安装高度，不能把它当成壳体尺寸缩放。

坐标定义：X 正向为出拳，Y 为左右，Z 为向上，Otto 身体顶部平面为 Z=0。默认曲柄轴 X=6，滑架铰接轴从 X=30 移至 X=50；拳套最前方从 X=69 移至 X=89。两根导杆沿 X=10..74 布置。主体最高 Z=58.8，安装圈最低 Z=-8。外耳使安装圈外宽增至 89 mm；头部前伸、顶部重量及碰撞反作用需在整机上检验。

公式：`s = cx + r*cos(theta) + sqrt(L^2 - r^2*sin(theta)^2)`。当 theta=180°时收回，0°时打出；最大连杆偏角约17.1°。这是刚性几何关系，不包含电机转速波动、摩擦、变形或惯性。

## 5. 打印哪些零件

| 编号 | 零件 | 数量 | 材料/注意事项 |
|---|---|---:|---|
| 01 | 平台、减速器托盘与导杆支座 | 1 | PLA/PETG 试装；水平轴孔需检查支撑/桥接，平台扎带通槽不要堵住 |
| 02 | 双扁孔曲柄 | 1 | 硬质材料；轴孔尺寸由08量规确认，不能整件缩放 |
| 03 | 连杆 | 1 | 平放打印，转动孔清理圆滑 |
| 04 | 滑架与腕部舌头 | 1 | 导杆孔朝X；孔内去支撑并试滑，不能卡滞 |
| 05 | 空心拳套 | 1 | TPU 为接触件候选；底部留清理口，切片检查内腔支撑；PLA可作尺寸样件 |
| 06 | 通用传感器支架 | 0或1 | 选型前可不打印；不是现成限位开关套件 |
| 07 | 身体开口量规 | 1次试装 | 套合尺寸验证 |
| 08 | 减速输出轴孔量规 | 1次试装 | 双扁轴配合验证 |
| 09 | 身体安装圈 | 1 | 上下贯通，外耳下方有M3六角螺母窝 |

减速箱如未装配，还需官方上下两片壳体、LA016 非打印齿轮/轴及 LA024。参考壳体导出保持厂家安装方向并仅移到Z=0，**没有优化打印朝向**；根据官方装配指南和切片预览自行翻转，不能把壳体内的空腔填满难拆支撑。

0.2 mm层高、3–4圈墙可作为硬质零件试装起点。具体填充、支撑、孔补偿和TPU参数以你们打印机实测为准；本包没有生成打印机专用3MF或G-code，没有计算真实耗材重量或打印时长。

## 6. 装配顺序

1. 确认实际是 LA024 和 LA016；按官方指南装好减速箱。若已有不同外壳，先比较外形和轴位，不能强塞本托盘。
2. 用07检查身体套合，用08检查减速输出轴。双扁孔应能推入且无明显空转，不能靠敲打电机轴装入。记录松紧再改局部间隙。
3. 将09套圈装到身体上。原身体两侧固定方式沿用已有方案，孔中心低于上沿4 mm；如果已有孔不相符，先核对后再调整模型。内部主板/电池位置尚未检查。
4. 把四颗M3螺母放入09下方外耳槽，用四颗M3×12从01上方连接平台。下方支承面应贴合，无晃动。
5. 减速器放入托盘，用两根约2.5 mm宽尼龙扎带穿过平台左右通槽固定。扎带从壳体上方及平台下方绕过，远离旋转轴；切除多余尾带。穿扎带需要平台下方可接近，可在第4步锁平台前预穿。电机线从后部开口引出，不能跨过曲柄扫掠区。
6. 将02装到减速输出双扁轴上，使用**与原塑料输出轴中心孔匹配的锁紧螺钉**从上方固定。当前通孔Ø2.7、沉头空间Ø5.2×2.1只定义避让，不证明某颗螺钉能可靠咬合。头部必须低于曲柄顶面，不顶住上方连杆；实测螺钉尺寸不符时改参数或结构。
7. 两根Ø3×64导杆从前支座穿入，穿过04滑架，再插入后方盲孔，杆后端抵到X=10。前支座顶部使用两颗M3×6紧定螺钉压住杆（Ø2.6底孔需加工螺纹/试锁）。先确认滑架全程手推顺畅再锁紧。
8. 曲柄→连杆：M3×16低头螺钉从下向上穿过曲柄，放2 mm轴向间隔垫，再穿过连杆，顶部薄垫圈和M3防松螺母。连杆必须能自由转动，不可把两片夹死。间隔垫外径不超过6 mm、内孔约3.2 mm。
9. 连杆→滑架：M3×25低头螺钉从下方穿过连杆，放同样2 mm间隔垫，再穿过滑架中心孔，顶部薄垫圈与防松螺母。选有光滑轴段的连接件更适合反复运动；实际头/螺母超出报告使用的包络时需要复核。
10. 将05套到滑架前端舌头，M3×20加垫片与螺母穿过腕部孔固定。紧固件应固定舌头，不能压瘪空心拳套。
11. 不通电，手动转动曲柄一整圈，确认导杆不卡、螺钉可通过、线材不被勾住、拳套不碰支座。再做独立台架低速测试；头部装上整机后重新检查站立、行走和顶部负载。

## 7. 手柄控制约定

**本次只交付建模和控制接口说明，没有上传电机程序或改动现有四腿控制。**

- LA024接接收板空闲的直流电机口M1或M2，不占四个腿部舵机口。接口能力已从本地与官方 `bbl/motors.py` 核对；具体系统接入仍需处理已有控制程序对输出的所有权。
- 最简单的模式：按住指定攻击输入，电机持续同方向运行，拳头连续打出/收回；松开立刻停机，**可能停在中间位置**。
- 如果要“按一次只打一拳、松开也完成收回”，要增加原位传感器，并用“离开原位→再次进入原位→停止”的一圈状态逻辑；还要有超时停机、失联停机和显式恢复。仅用延时不能保证复位角度。
- 06只提供通用安装槽，没有选定/安装传感器、触发片和电气输入，不算已完成回位检测。选型后应补专用支座和触发件。
- 现有K4在行走程序中承担停止，不直接把它复用成攻击。攻击通道需要在实际手柄上确认可用摇杆轴/按钮后分配。
- 紧急停止和失联应立即停电机，不为“强制收回”继续驱动。恢复不能自动出拳。

官方马达规格为额定8V、空载10500±10%rpm；除以48的理想空载输出约219rpm，即3.65次往复/秒，**不是建议起始动作速度**。真实负载转速、齿轮效率和低占空比起动能力未知，需要台架确定。不能从减速比直接宣称出拳力量或可靠性。

## 8. 验证边界

脚本会检查：每个自建打印件为一个有效实体、STL闭合、连杆几何闭合；按指定步长采样整圈，对新建固定件、官方壳体/马达包络、曲柄/连杆/滑架/拳套、两根导杆以及两处转轴紧固件包络检查实体重叠。曲柄孔与随动输出轴同步旋转检查，避免把固定相位的轴误当障碍。

报告没有检查：连续时间所有角度、厂家齿轮啮合、实际打印公差、螺纹、完整紧固件/扎带、运动中的电线、真实机身内部空间、传感器实体、受力/疲劳、摩擦、质量重心、跌落、供电与无线控制。

后续首先补齐实物尺寸和打印试装反馈；通过数字检查不等于机械验收。来源与测量记录见 `资料核对与设计依据.md`。
