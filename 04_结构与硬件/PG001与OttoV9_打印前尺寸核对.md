# PG001与SG90、Otto V9打印前核对（2026-09-19）

本次将用户“90舵机”理解为SG90，“Auto模型”理解为项目中保存的Otto V9。

结论：同属相近尺寸微型舵机，现有证据支持100%比例先打印一条腿和一只脚做试装，不支持宣称已验证整套免修改。若为了抢打印窗口同时打印两个腿壳，可作为风险可接受的试件，但可能需要局部修整或重打；尚未做完整CAD装配干涉分析。

## 数据来源

- SG90原厂：https://towerpro.com.tw/product/sg90-7/ ，标称23×12.2×29mm。不同厂商仿SG90不能保证相同尺寸。
- Otto官方：https://www.ottodiy.com/blog/ottodiykit ，基本结构使用4个SG90 9g微型舵机。
- PG001：用户提供尺寸图及此前下载官方规格，图示23mm、12mm、27.30mm；安装耳总长32.50mm、孔槽中心距27.80mm，槽径2.20mm。不能混淆壳体尺寸与安装耳总长；高度须按原图基准核对。
- PG001原配舵盘接口为40T/直径4.85mm，应复用其原配舵盘，不默认与SG90舵盘通用。

## 实际检查的本地模型

`01_研究参考/robot-battle-reference/Otto-V9/3Dprint/OttoDIY_Leg_V9.stl`

直接解析二进制STL顶点和轴向平面：腿部整体包围尺寸17×38×42mm（原文件坐标），主要两侧内壁位于x=19与x=32，间距13mm；局部下端平面位于x=19.375与31.625，间距12.25mm，该局部结构不能简单当作整段舵机仓净宽。因此仅用13mm与12mm相减不能证明整个安装路径都畅通。打印收缩、圆角、接线出口与舵盘槽还需试装。

`OttoDIY_foot_V9.stl`外形包围尺寸42×64×27mm。此为零件整体尺寸，不是舵机仓尺寸。腿、脚、机身均有连接关系，打印两个腿壳并不等于完成完整腿脚总成。

## 建议本轮打印

优先：腿壳1件＋脚1件，保持100%比例、按切片软件正确摆放；不要因源STL含装配坐标偏移误缩放，也不要为了松配整体放大。

试装顺序：舵机能放入且不受挤压 → 安装耳与支撑定位匹配 → 原配舵盘能嵌入相应结构 → 中心螺钉可装卸 → 合上脚后轴心无偏斜 → 未通电时检查线缆和机构活动空间；确认后打印另一侧。左右脚方向/镜像方式按原装配说明核对，避免把一侧成品当作两侧通用。

如果用户坚持趁空档先打两个腿壳，可以原尺寸作为试装件先打；准确表述是“尺寸接近，值得试打”，不是“已经确认无需修改”。仍暂缓整机外壳，因为CB1核心＋接收板＋电池布局需单独适配。
