# 第二台拳头机器人：基本完成交接

更新时间：2026-10-17（北京时间）。用户最终确认：“没问题了，拳头机器人基本好了”。本文件优先于此前的限时测试、K4 急停、跳舞幅度待确认等旧记录。

## 当前可用功能

| 操作 | 实机确认的行为 |
|---|---|
| 接收板上电 | 自动启动第二台持续遥控，无测试倒计时 |
| 左、右行走杆 | 控制现有 Otto 连续步态的行走及转向；用户确认两杆可用、稍后再推仍响应 |
| 拳头杆上推 | M1 同方向慢拳，速度指令 1024 |
| 拳头杆下推 | M1 同方向快拳，速度指令 1800；用户确认明显更快 |
| 拳头杆持续偏转 | 一直运动，不再因单次出拳限时停止 |
| 拳头杆回中 | 停止 M1 |
| K4 按住 | 暂停普通行走请求、停止 M1，四腿交替摆动跳舞 |
| K4 松开 | 结束跳舞，恢复普通遥控 |

跳舞最终参数：四关节目标偏移均为 ±25°；每次幅值取上限的 80%–100%，左右侧交替，300ms 平滑移动、150ms 保持，再反向。绝对输出限制为 65°–115°。用户在该版上传后确认“没问题了”；此前小幅版本仅作历史，不再是当前配置。该确认不代表长期可靠性或全部负载工况已测完。

## 硬件、通道与程序

- 第二台接收板：USB 序列 `80:F1:B2:1E:0F:FC`，本电脑 COM9，GPIO10=0。
- 第二台发射板：USB 序列 `80:F1:B2:1D:43:3C`，本电脑 COM10；换电脑后端口号可能改变，按序列号辨认。
- 四腿：S1 左髋/GPIO3、S2 左踝/GPIO2、S3 右髋/GPIO1、S4 右踝/GPIO0。左右按机器人自身定义。
- 拳头电机：M1，板载驱动 GPIO4/5，通过 `bbl.motors.MotorsController` 控制。驱动范围 -2048～2048；当前两档均为正值，不反转机构。
- 遥控映射：左行走 ch3、右行走 ch0、拳头 ch2、K4 ch9（低电平按下）。拳头上推高值约4076，下推低值0，中位约2100；配置中位2146位于死区内。
- 原厂接收板 `boot.py` 已禁用，保留 `boot_official_disabled.py` 备份；两板叉车配置的 M1/M2 自动控制绑定已移除。发射板仍使用原厂无线启动，不可照接收板方式禁用。

第二台源码目录：`05_程序与测试/CB1_Otto控制框架_v02/`。
