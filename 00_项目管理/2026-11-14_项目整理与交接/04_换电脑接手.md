# 换电脑接手

## 获取这次整理
仓库：https://github.com/paomodabaibai/CyberBrick2-User-Research-UX
分支：project/2026-11-14-management-sync（通过PR交付；合入前不要只拉main后认为已拿到新版）。

```text
git clone --branch project/2026-11-14-management-sync https://github.com/paomodabaibai/CyberBrick2-User-Research-UX.git
git lfs install
git lfs pull
```

先安装Git与Git LFS。若已经克隆，先保存自己的改动，git fetch后切换此分支；不要强制reset清掉未提交修改。

## 阅读顺序
1. PROJECT_CONTEXT.md
2. 本目录01_项目看板与下一步.md、02_机器人版本与接口.md
3. 05_程序与测试/双机2.0当前程序包_2026-11-14/README.md
4. 04_结构与硬件/逐步装配教程_v12_2026-11-12/02_主板与攻击模块_逐页图解.pdf

GitHub页面不能直接运行本地HTML预览，下载完整目录后用浏览器打开；只要看装配先用PDF。

## 环境与设备
Python串口环境未入库，按requirements-serial.txt新建虚拟环境安装依赖。不要复用本机E盘Python绝对路径。COM号会变，按板卡序列核对机器，保留官方app/bbl/配对信息；此仓库不包含完整厂商固件。

## 视频媒体
最终成片通过LFS获取，DRP可编辑工程与脚本也在库内，但大原片/达芬奇转码/中间渲染没有上传。依据视频本地素材索引.json从原电脑另拷媒体，再重链接；不要把DRP能打开当作所有素材齐全。

## 现场备份
原厂板端备份和rc_config保留在原电脑，没有公开上传。需要回退时先找原电脑对应“现场备份”目录，不能拿另一台机器的配对文件代替。
