# 换电脑继续 milk 组项目（2026-10-11）

本仓库的 `main` 是团队共享的可继续工作版本。项目实际采用 **CyberBrick 1（CB1）** 套件，仓库名中的 CyberBrick2 是早期命名；不要据此给当前两台机器上传 CB2 固件或接线方案。

## 新电脑获取资料

```powershell
git clone https://github.com/paomodabaibai/CyberBrick2-User-Research-UX.git
cd CyberBrick2-User-Research-UX
git pull origin main
```

优先读 [项目上下文](../PROJECT_CONTEXT.md) 顶部、[接手摘要](继续任务_给其他Agent.md) 顶部、[CB1 双机接口表](../04_结构与硬件/CB1双机接口对照_2026-10-11.md) 和[Otto 组装速查](../04_结构与硬件/Otto_V9组装速查_2026-10-11.md)。这些文件下方保留历史调试记录；日期新、明确标注实测的结论优先。

## 当前硬件与软件边界

| 设备 | 已经实测 | 尚未完成 |
|---|---|---|
| 第一台：巴掌 Otto | 四位置舵机、遥控连续步态/转向/倒退、D1 连续舵机巴掌均已用户观察验收 | 长时间供电与攻击方向语义等小项仍可复核 |
| 第二台：拳头 Otto | S1–S4 逐路 90→110→90 正常；脚本短时落地前进；M1 电机单向半速持续 5 秒正常 | 第二台遥控配对/输入映射、行走与拳头并发、正式自启动、反转/长时负载 |

两台的四路接线均为 S1/GPIO3 左髋、S2/GPIO2 左踝、S3/GPIO1 右髋、S4/GPIO0 右踝；第一台 D1/GPIO21 连接巴掌连续舵机，第二台 M1/GPIO4/5 连接拳头直流电机。第二台当前板端只上传了短试脚本，**不要把第一台的 `boot.py` 或 `otto_session` 直接覆盖到第二台**。接收板与遥控发射板需要分别辨认；COM 号码会随 USB 重插变化，不应写死。

第一台控制入口为 `05_程序与测试/CB1_Otto控制框架_v02/otto_session.py`，相位生成在 `otto_oscillator.py`，巴掌在 `attack_control.py` 和 `drivers/palm_pwm.py`。第二台短试脚本是 `second_otto_walk_test.py`、`second_m1_motor_test.py`；其真实动作与限制见 [第二台实测记录](../05_程序与测试/CB1_Otto控制框架_v02/2026-10-06_第二台机器人实测记录.md)。拳头打印件与装配入口在 [全套打印包](../04_结构与硬件/拳头_全套打印包_2026-09-29/先看这里_打印与装配.md)；队友的原始参数化结构在 `04_结构与硬件/Otto_CB1出拳头部_v01/`。打印包的 05 号拳头已含腕杆；03 号是曲柄到滑架的连杆。

## 新电脑准备串口工具与验证

Windows 安装 Python 3.11 后，在仓库根目录执行：

```powershell
py -3.11 -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install -r requirements-serial.txt
```

原电脑的 `05_程序与测试/serial_runtime/` 没上传，它是可重建的本地 Python 环境。控制逻辑的 PC 回归测试不需要硬件；在 `05_程序与测试/CB1_Otto控制框架_v02` 内运行：

```powershell
& '..\..\.venv\Scripts\python.exe' -m unittest discover -s tests -p 'test_*.py' -q
```

截至本次同步，151 项控制框架测试在原电脑通过。新电脑环境和板端串口仍须分别验证，PC 测试通过不表示实机动作通过。若要让接收板 S1–S4 持续保持 90°，接上**一台**接收板并扶稳机器人，进入该控制代码目录后运行：

```powershell
& '.\发送四舵机90度.ps1' -Port COM9
```

将 COM9 改为设备管理器显示的实际端口；只连接一块接收板时也可省略 `-Port`。脚本先核对 GPIO10=0 才上传，且不改动 `boot.py`。带腿脚的机器人收到 90°命令可能突然回中，保持电池开关在手边。遥控器配对数据、板端文件系统、已安装舵盘的机械齿位都在实物上，**GitHub 不能恢复这些硬件状态**。
