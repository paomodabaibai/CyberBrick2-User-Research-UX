# milk 双机机器人：项目全貌与模型审查交接

整理日期：2026-10-28。用途：让另一个 Agent 独立检查当前模型，不从头重做项目。

**一句话状态：两台旧版实机已有行走、遥控与攻击；现在做的是为新增四台而进行的可装配、可维护与外观改版。当前 v06 是模型审阅候选，尚未完成制造设计或实物试装，不是批量打印包。**

## 1. 项目在做什么

milk 组（第2组）课程项目：桌面双足机器人对战。成员傅宬博、白昊灵、孔舒然、罗圣希。目标是让用户遥控小短腿机器人接近、转向和攻击，产生直观、滑稽、可互动的实体游戏体验。

- 蓝色巴掌型：Otto V9 双足基础 + 顶部连续旋转舵机 + 横向巴掌接杆和卡通手掌。
- 红色拳头型：相同双足基础 + 电机驱动曲柄/连杆/滑架，实现往复出拳；灵感来自 James Bruton Punchy，现用项目定制机构。
- CB2 已停用，当前是 **CyberBrick 1**，不可照CB2接口或外形建模。
- 四条腿部通道实为四关节：S1左髋、S2左踝、S3右髋、S4右踝；左右指机器人自身方向。四只180°位置舵机；巴掌攻击另用360°连续旋转舵机D1；拳头电机M1。
- 两款行走与K4跳舞交互应一致，仅攻击杆输出不同：巴掌正反转；拳头上推慢、下推快；回中停。K4按住跳舞、松开停，**不再是急停键**。
- 实体竞技场用户已确认搭建，最新场地为80×120cm；场景/磁吸脱落球靶是配套玩法。早期NFC技能卡、道具点只是设想，不是已完成系统，不为其盲目加大机器人。
- 下一阶段是11月12日下午北京拓竹线下门店活动，计划现有2台 + 新增4台 = 共6台，红蓝各3台。装配一致、易维修、能稳定演示是本次结构检查目的。

## 4. 关键尺寸和装配约定

- 单位mm；+X向前、-X向后、+Z向上；身体顶面Z=0，底面Z=-39；Y为左右轴。左右命名最终与实物同一观察基准核对，不能用屏幕左右代替。
- 身体主壳75×75，局部前电池仓/后开关凸台使总外包不等于简单75方盒；原Otto下部与新上壳混合。整机高度不能用“身体39mm”代替。
- 顶部四个固定轴位(X,Y)=(±30,±30)；拳头后侧两孔(-30,±30)。后护罩U口半径4.2mm；现有工具检查为直径6mm竖直柱。
- 前顶部柱缩短到6mm以让电池；后部柱13mm。前后不能默认同一螺钉长度，必须按真实夹紧叠层计算。
- PC003电池本体28.4×51.2×16.3；v05立放包络X18.2..34.5、Y±25.6、Z-35.5..-7.1。CAD中的长直线不是实际走线。
- 接收板与核心板按完整组合建模，后置竖放；官方PCB安装孔约2.7mm，**不能当M3通孔**。板卡固定可参考M2.5，身体夹紧另用M3；须核实实物。
- 针排附近预留10mm插头+8mm弯线，仅为占位假设，不代表所有线束建好。
- 巴掌75mm、轴心至杆末端孔组中心51mm；接杆底Z39.97；转轴X5.34,Y0。
- 新承重座径向运行间隙0.3mm、轴向0.4mm，原配半臂舵盘槽侧隙0.3mm、顶隙0.4mm；均为试配起点。打印件不直接硬压花键。
- 圆角盖Z3..37，外缘受距转轴49mm限制；手掌参考网格最小半径约51mm。此余量不包含真实变形、装配偏心和螺钉。
- 拳头模块后移22mm，曲柄偏心10mm、连杆34mm、导杆Ø3×64mm沿用。实际拳头采用用户微调后的网格，不用旧网页参数重新覆盖姿态。
- 椭圆眼睛在X=37.5前面，Y±13，Z=-13，尺寸10×15mm、凸出2.4mm；平背粘贴，不在身体开通孔。

## 6. 接手 Agent 的工作顺序

1. 读本文与《模型审查任务与验收表》，打开v06交互页，分别看两机整机、后背、内部与模块。
2. 对照官方CAD、v05布局与v06源文件，先确认版本、单位、坐标、实际网格及依赖；用附带SHA256索引确认是否审查到同一批文件。
3. 独立复核重点问题，先出缺陷报告和标注图。不要仅复述本Agent的检查结果；碰撞检查要补上真实紧固件/线束和完整运动范围。
4. 将“模型明确缺陷”“依赖实物尺寸”“需小样实验”分开。缺少供货型号/插头尺寸不能靠猜通过，也不要因一个待测项停止其余独立审查。
5. 本轮默认审查为主，保留原件。提出最小修改方案与具体文件；如后续获得修改任务，复制为新版本，更新生成器与模型，重跑受影响检查。
6. 达到条件后只建议一套试装/关键滑动副小样，先测能装、能维护、不卡线，再做真实负载与步态；通过后才形成新增4台的批量打印包。

请不要擅自连接串口、上传、复位、驱动机器人；不要更改两机控制功能；不要擅自删除归档或推送Git。这不是新增安全审批，而是本次“检查模型”任务范围。

## 7. 审查后应交付什么

- 一页结论：可继续试样 / 须先修正 / 等实物尺寸，不能只给“整体没问题”。
- 逐条R01–R16覆盖表；缺失功能尤其充电口不能遗漏。
- 缺陷表：优先级、零件、坐标/尺寸、依据、影响、最小改法、验证方式；带前后/剖视标注图。
- 一份精确的螺丝叠层与数量表，以及装配顺序和线束路线图。
- 分清可沿用零件、必须重打零件、需要外购五金/电子件、待测信息。
- 若尚不具备打印条件，列出具体剩余项；不要把“参考件/占位/装配STL”误发成打印清单。
