# 双机模型：独立审查任务与验收表

日期2026-10-28；先读同目录01。只做模型审查，不连接或驱动机器人。

优先级：P0=阻止装配、供电维护、运动或强度基本成立；P1=影响可复刻、维修、打印；P2=外观细节。以下是检查任务/已知缺口，不等于每项都已确认故障。

| ID | 级别 | 检查对象与方法 | 通过依据 / 需要的产物 |

| C01 | P0 | 核对180°腿舵机、360°攻击舵机、实际舵盘、板卡、电池、开关型号；对照官方CAD与实物 | 列出已知/未知尺寸；SG90不冒充PG001，连续舵机不放腿部 |
| C02 | P0 | 两侧髋壳体、安装耳、花键轴高、螺丝位置、出线口与原身体比较 | 叠图/差异尺寸；保守占位与原模型重叠相同不等于装得进 |

| C25 | P2 | 红蓝辨识、正背辨识、盖子圆肩、剩余工业感 | 保护功能与质量，不追加重型装饰/不堵数据口 |

## 审查执行节奏

第一轮：确认文件版本与电子参考 → C01–C13（能装、能接线、固定可靠）。
第二轮：C14–C17（巴掌承重与转动的核心风险）。
第三轮：C18–C25（维护、打印、重心、外观）。能独立验证的继续，不必等所有实物尺寸。

不要重复做无意义的全量软件测试来代替模型审查，也不需要重新研究已经确定的遥控方案。检查结果写到新审查目录，不覆盖现有证据。

## 打印阶段放行条件

- 关键接口与材料确定，全部P0至少有明确解决路径；无法仅靠数字验证的项目标为试样验证，不伪称通过。
- 先发关键承重滑动副小样及一台共用身体的试装清单，不同时发6台量产清单。
- 真正批量前：固定、供电/充电维护、完整布线、工具操作、全行程避碰、手掌静态支撑、低速正反转、带载行走与转向逐项实测。
- 最终交付每型独立打印目录（排除参考板、电池、舵机、包络），逐件数量/方向/材料、精确五金表、装配爆炸图和走线图。
