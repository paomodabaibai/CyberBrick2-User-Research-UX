## 怎么改

hermes python 指 `C:\Users\Administrator\AppData\Local\hermes\hermes-agent\venv\Scripts\python.exe`。下面前三个命令在 `工作区\动效_实拍段\` 运行。

**只改声音（不要渲染画面）：**

```powershell
py -3.12 tools\make_voice.py D 2                               # 人声版本 A/B/C/D 和增益 dB
py -3.12 tools\sfx.py out\音效_实拍段.wav                       # 合成音效改了才要
py -3.12 tools\mix_audio.py PocketChange_Fun.mp3 混音_v12.wav D
# 然后用 ffmpeg 把音轨换进两个最终版：-map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -movflags +faststart
```

**用户在达芬奇改了画面：**

1. 只保存工程并导出新底片，不要运行 `动效_规则段\tools\export_film.py`，它会替换 V2 第一个片段（现在是表情包）。
2. 把 `render.py`、`track.py`、`build.py` 里的底片路径改成新版本。
3. 只改 5.33–14.83、20.90–40.30 时直接跑第 5 步。改了三段特效段要先跑第 4 步。
4. `<hermes python> tools\render.py --plates`，再 `<hermes python> tools\render.py --all --only A`（或 B、C）。
5. `py -3.12 tools\build.py`，回工作区运行：`<hermes python> 动效_规则段\tools\burn_subs.py out\棋甲对决_竖屏抖音_最终版_无字幕.mp4 配音_v05\字幕_v05_短句_125527.srt out\棋甲对决_竖屏抖音_最终版_带字幕.mp4`

**用户在达芬奇改了声音：** `分轨_无人声.wav` 和 `人声摆放表.json` 要重做。它们来自 `动效_实拍段\out\分轨_全混.mov`（无损全混）减去 C 版人声：逐句最小二乘求增益，当时每句 -3 dB、第 10 句 0 dB，零偏差。改片段位置后这张表也会失效。

**改动效：** 规则段重渲很慢（每秒画面约 60 秒，整段约 20 分钟）：`<hermes python> 动效_规则段\tools\render_fx.py --mode alpha --out 动效_规则段\out\规则段_v7.mov`，先用 `--mode preview --stills 1.1,2.9 --out 目录` 看定格。

**封面：** 源帧在 `封面备选\源帧\`。取帧用 `已命名素材_达芬奇转码\` 的 mov，颜色和片子接近；`已命名素材\` 的原始 mp4 偏橙。

## 环境坑

- **手机审片**：小米 14（adb 序列号 264ae50b），需要用户插线并开 USB 调试。Git Bash 会改写 `/sdcard` 路径，用 PowerShell 跑 adb，或设 `MSYS_NO_PATHCONV=1`。默认打开方式会跳网易云音乐，要指定 `-n com.miui.mediaviewer/com.miui.videoplayer.ui.LocalplayerActivity`。手机存储几乎满（约 700M 可用），传新样片前先删旧的。
- **达芬奇脚本**：MCP 工具常报“未运行”，要用户运行 工作区 → 脚本 → resolve_bridge，端口看日志，会变。`SetRenderSettings` 一次传错一个参数整批失败。`SetTrackEnable` 对渲染无效（关音轨导出的还是全混）；纯音频导出的 `StartRendering` 常返回 False。别靠脚本分轨。
- **Python**：`python` 是 hermes 同款，有 playwright，没 numpy；`py -3.12` 有 numpy、faster-whisper。`extract_frames.py`、`track.py`、`prep_models.py` 依赖 OpenCV、trimesh，新对话要重装（`py -3.12 -m pip install --target <目录> opencv-python-headless trimesh fast-simplification scipy networkx`）并改脚本顶部路径，只有改模型或追踪时才需要。
- **ffmpeg**：Git Bash 下 `drawtext` 不指定 `fontfile` 会崩，要写 `fontfile`。`cv2.imwrite` 写不了中文路径，要先 imencode。PowerShell 脚本有中文要存成带 BOM 的 UTF-8。
- **通配符**：文件名“机器人在上”也包含“人在上”，移动文件别用这类通配符。
- 时间线备份在 `工作区\达芬奇交接\*.drp`。方法沉淀在 `E:\AI视频\通用制作方法`（`文档\06_实拍叠加动效与打击特效.md`、`工具\实拍打击动效\`、`技能\live-action-impact-fx\`）。
