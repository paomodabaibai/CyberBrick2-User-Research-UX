# milk 组桌面双足对战机器人（当前使用 CyberBrick 1）

仓库名沿用早期 CyberBrick 2.0 命名；当前两台机器人实际使用 **CyberBrick 1**。这里集中管理用户研究、方案汇报、视觉素材、结构建模、控制程序与实测记录。

## 当前重点

- 旋转巴掌机器人：遥控行走、转向、倒退和巴掌攻击已实测。
- 出拳机器人：短时脚本落地前进和 M1 拳头电机单独运行已实测；遥控与并发控制尚未完成。
- 项目资料：研究结论、竞品与参考资料、提案文件、硬件 BOM、串口控制原型。

## 协作约定

1. 开始工作前先拉取 `main` 的最新内容。
2. 每项工作新建短分支，例如 `mechanical/punch-head-fit` 或 `control/home-sensor`。
3. 提交信息写清对象和结果，例如 `调整出拳滑轨间距至 24mm`。
4. 通过 Pull Request 合并到 `main`，在描述中注明改动、验证方式和待确认事项。
5. CAD 参数与生成结果同步更新；物理试装结果写入对应验证记录。

## 本地生成环境

运行时、依赖缓存、第三方应用只读副本和重复交付压缩包不纳入版本控制。出拳头部可在其目录中按说明安装依赖并重新生成 STL、STEP、GLB、预览图和运动验证文件。
