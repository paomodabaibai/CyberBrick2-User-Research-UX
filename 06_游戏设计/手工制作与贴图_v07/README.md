## 摆位与装配

底板从西向东排列：南排F1/F2/F3，北排F4/F5/F6。桌面需要全幅承托底板；背面跨缝贴不大于0.1厚的薄透明胶带，不用厚布基胶堆叠垫高接缝。拼缝建议控制在0.5以内，高差0.2以内，并用机器人试走确认。地面无需满贴纸，避免纸边翘起。

墙竖片放在40宽脚座正中，两侧各留17.5。先贴墙面装饰，再剪开加强片胶合位置露出板材；竖片和加强片用板材胶粘牢，脚座再用薄双面胶固定到地板。脚座属于障碍，通道尺寸量到脚座边缘。

护沿南北各3根420长，东西各2根610长接在南北护沿之间。四角不重叠。护沿用胶固定，不能仅靠木条自重；它不等于已经验证能防止重机器人跌落的围挡。

## 球靶做法和必须现场定的尺寸

每颗Ø70球用两条260长的织带做正交闭环，用布基胶带包牢重叠与底部交叉处。硬帽固定到顶部布带，钢垫圈固定到帽上并用胶带跨压边缘；绳绑在帽旁织带。承重由布兜承担，不能只把钢圈粘在软球皮上。

200长挑臂前端在球前20、后端在球后180，后柱中心在球后150。磁点距臂前端20，导孔距前端60。臂下小磁铁固定并包封，钢圈随球一起掉落。磁点过强就用薄纸垫逐层减弱，先做一套试打再复制。

设H为实际需要的球心高度，t为**木臂底面到裸球顶的总距离**，包含磁铁、封胶、纸垫、钢圈、硬帽和布带。则臂底高度U＝H＋35＋t，木柱净长＝U−底座厚5。示例H135、t8时U178、柱173；135不是实机验收值。

每根绳先裁300。穿过磨圆的3～4导孔，上端设止挡珠，珠外径至少10，珠上方打结且结大于珠自身孔。把球底临时垫高20，止挡珠抵孔上口，再调绳并锁结；这样把低位定为球底20、球心55。绳上部多余段放在臂顶开放浅纸槽，不要在球旁留松环。

示例U178、系绳点近似裸球顶时，孔下有效绳长88、孔内另有20，初始孔下斜段约40.79、上方可抽余绳约47.21。实际帽和绳结高于球顶时，用垫高20的方法现场定长，不直接按88裁绳。

以t8和导孔后40为例，H至少约87.8才有足够绳长挂回磁点；为保留明显落差，设计建议H至少95。220柱毛坯在t8时最多支持H182。超出这一范围需改柱或导孔位置；不能只改一个标注数字。

实测需覆盖：攻击最高点与臂的间隙、巴掌扫掠不带住细绳、机器人身体不先撞底座、两种攻击都能触发、普通行走不误触。后柱150仅是初样；球脱落后的全摆幅可能触柱，命中后停机，检查不缠绕再复位。

判定：**脱开上磁点并降到低位才计分；只有晃动不计。** 身体撞架、手碰导致误脱则复位。先有效命中自己颜色球者胜。
