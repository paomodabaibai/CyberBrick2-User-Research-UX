# 磁吸脱落球靶 v06｜明确形态与命中状态

2026-10-13。状态：靶模块构造方案，待实物试打；不是已经定版的打印模型。

## 本次确认与推荐

用户已确认：命中结果必须肉眼明显，并在命中后保持到人工复位；允许悬挂小球等精巧目标，目标不必全由3D打印完成。此前“禁止悬挂目标”的限制已被本次允许所更新；地图行走面仍是单层平地。

本版推荐 **磁吸脱落球靶**：一颗鲜明的红色/蓝色软球，顶部通过硬帽上的钢片吸在挑臂端部磁铁下方。球受到有效攻击后脱离磁点，由限位细绳接住，降到低位。支架保持原位，下一局人工把球挂回。

这是对目标形态的推荐，不代表磁力、实际击打高度或两机触发公平性已确认。

## 看得见的两个状态

| 状态 | 球的位置 | 玩家看见什么 |
|---|---|---|
| 待击 | 球顶贴在上方磁点；限位绳不承担球重 | 鲜明彩球悬在攻击高度 |
| 命中后 | 球脱开磁点，下落后被限位绳接住 | 上方磁点空了；彩球明显降到下方，并一直留在低位 |
| 复位 | 人工挂回磁点，并把多余绳段收回上方浅槽 | 回到待击状态 |

**判定：攻击机构使球脱离上方磁点并进入低位，即算有效命中。仅转动、晃动、未脱开不算。** 支架被身体撞动或桌面震动造成脱球，暂停复位。双方仍是红方打红球、蓝方打蓝球，先有效命中指定目标者胜。

球不靠长绳自由摆动来判定。命中前主要靠磁点定位，命中后细绳只承担防掉出场地与保持低位的作用。不增加电子传感器、开关或任务链。

## 具体形态与材料

| 部件 | 初样规格 / 做法 | 制作方式 |
|---|---|---|
| 彩色软球 | 直径70，先以轻质泡棉或海绵球试做；红蓝同款、同重 | 外购，不打印重实心球 |
| 球顶硬帽 | 承托一小片钢片，固定在球顶；不能只把钢片随意贴在易撕泡棉表面 | 小打印件或手工硬片，按真实球材质选固定法 |
| 磁点 | 磁铁固定并包封在支架端部，球上只放钢片 | 小磁铁试样，例如Ø6×2或Ø8×2；规格不代表已知吸力 |
| 调力垫 | 磁铁与钢片之间尝试约0.1～0.5薄纸/胶片垫，逐步调保持力 | 常见薄片；每次记录组合 |
| 挑臂与后柱 | 挑臂前伸约150；柱位于球后150；示意柱高230、截面16×20 | 木条、金属条或打印均可；230柱若打印须分段或改构造 |
| 限位绳 | 光滑、轻、低伸长的细绳，经圆滑导孔；上端止挡结不能穿孔 | 外购；绳长按装好后的自由段量，不按未打结裁长直接判定 |
| 地板固定 | 后柱底部锁在齐平替换地板，紧固件沉入底面；与原地板连接保持平整 | 后续按实测高度和载荷建接口；球前不加宽配重圆盘 |

磁点小型化、垫片调力只是试样方法。目标是先找到“普通行走和桌面轻振不误落，实际攻击能脱开”的区间；若两者无法兼顾，必须修改磁组件或球重，不能用更大攻击动作掩盖问题。

## 尺寸示例：把落差算清楚

以下高度全部从地图**行走面**起算，地图原地板厚6不再计入这些高度。135仍是示意值，不是项目实测击打高度。

- 球直径 D=70，半径 R=35。
- 待击球心 H=135；球体范围100～170，磁接触点约170（硬帽、钢片、薄垫的实际厚度需补偿）。
- 导孔下口 U=180，位于球后40。挑臂示意底面180、厚10；该高度不等于已经避开巴掌扫掠。
- 最终有效绳长 L=90：指止挡结抵住导孔时，从导孔下口到球顶系点的有效悬垂距离，忽略小硬帽厚度作示例。
- 球脱开后最终在导孔正下方：后移40，球顶90、球心55、球底20；与初态球心相比下降80。
- 初态球顶到导孔直线距离约 √(40²+10²)=41.2，因此约48.8余绳收在挑臂上方的开放浅槽内。下落时绳段自由抽出，止挡结最后抵孔；不在球旁留悬垂绳圈。

高度关系：

```text
落后球心 = U − L − R
球心落差 Δ = H − (U − L − R)
离地空隙 = H − Δ − R
```

每次调整球心高度H，都应重新核对导孔高度U、有效绳长L与落差Δ。建议初样保留至少20离地空隙：H−Δ−R≥20。例：H=110、R=35时，落差最多55，不能照搬80落差；若U仍为180、L仍为90，低位球心自然保持55，落差自动变为55，此时不必改绳。若导孔随球一起升降，通常需要调整有效绳长。

**90是孔下有效悬垂段，不是裁绳总长。** 导孔穿过约10厚的挑臂，实际结到球顶系点的绳段还要加入孔内穿行长度及打结余量；装好后以止挡结抵孔时的真实低位球高校正。

上方浅槽是开放的收绳位置，不能卡住绳或让止挡结滑穿导孔。验证中如出现松绳进入攻击区、缠绕手掌、导孔摩擦阻碍下落，必须调整布绳后再玩。

## 两种攻击机构的空间

球面提供较大的接触区域，正拳可从正面推动，旋转巴掌可从侧向扫中。但不同受力方向下的剥离/剪切触发难度要分别实测，不能凭球形认定完全公平。

支架正面与左右侧开放，后方是支架区，不宣称360°无遮挡。支柱后置150，目的是把结构从球前移开，减少脚或身体先碰底座。最终需要同时检查：

1. 攻击件先碰球，脚、身体、支架不提前相碰。
2. 挑臂、磁杯、硬连接和绳都不进入巴掌真实完整扫掠。
3. 挑臂底面应依据实测攻击最高点和预留量设定，不能因为球顶170就认定臂底180安全。必要时抬高挑臂、用短硬连接下探磁点，并再次检查该连接。
4. 攻击停止后球能下落到低位，不被臂、柱、墙或绳环挂住。

## 第一轮只做这些

每边先做1套同款靶，不批量改地图。分别测两机接触高度和完整扫掠，调整球高、臂高、支柱距离和绳长，再进行：

- 静置、旁边行走、轻触桌面：观察是否误脱。
- 正拳、左右侧向巴掌：各记录10次有效攻击的脱落数与身体误碰数。
- 每次脱落都检查低位是否明显、是否卡绳、是否自动吸回。
- 连续复位，确认钢片硬帽、绳结、磁杯和后柱没有松脱。

记录真实结果后确定球材质、磁铁/垫片组合和高度。当前没有虚构通过率、触发力或击打阈值。
