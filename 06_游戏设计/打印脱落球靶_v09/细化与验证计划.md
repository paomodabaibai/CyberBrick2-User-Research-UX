# 球靶打印初样实施计划

目标：把已获同意的下托磁吸球靶变为分件可制造的第一套试装包，不把CAD验证说成实机试打通过。

架构：统一地面Z=0；球径60，默认球心135，125/135/145三档。方柱18×20，套筒单边间隙0.3；M3贯穿螺栓定位。套件CA001磁铁4×2，两侧均封在打印件内，中心1对或外圈对称3对可选。球壳分两半，胶合定位环。所有新件放本目录的制造初样_v01，不覆盖概念文件或机器人文件。

工具：CadQuery实体，trimesh网格，VTK实模型渲染；不连接机器人。

- [x] 生成制造件：底座/柱/套筒臂/磁座/磁座底盖/球上下半壳/接缝环/球内磁铁盖。
- [x] 明确现成五金安装方向与通道；选用M3×30定位，M3×16磁座固定；常规M3六角螺母5.5对边、约2.4厚。
- [x] 增加滑动间隙、磁铁孔和螺母孔的先打印小样。
- [x] 检查每件单实体、有效性、水密性、打印朝向、尺寸、所有三档下实体不干涉；检查磁铁封盖及五金实体空间。
- [x] 输出STL/STEP、可视化总装、装配图、打印数量与顺序、磁铁极性与吸力试验、固定场地的方法和未验证边界。

验收原则：检查失败先修复再导出。全套文件是机械初样；先完成小样试配和一套试打，再复制第二套。打印公差、层间强度、磁力与现场安装强度无法由CAD代替。
